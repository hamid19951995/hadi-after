# Foundation v14 — Zero-to-Render Autonomous After Effects Runtime

Adds manifest-driven creation of a new AE project, folders, compositions, solids, text and shape layers, keyframes, optional assets, real render operation routing, project save, checkpoints and snapshot-based rollback. The ExtendScript adapter is extended with v14 project/folder/text/shape operations.

## Start point
Use `foundation-v14/templates/default-animation.json` as a job manifest and provide a bridge transport connected to After Effects.
