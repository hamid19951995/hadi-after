# AE BOSS OMEGA Foundation v24 — Reference-Guided Motion Pack Studio

v24 turns the runtime into a modular motion-graphics planning layer that can generate original professional projects inspired by the structural language of user-supplied references.

## Added
- Motion Pack Catalog: characters, actions, props, backgrounds, icons, shape/UI elements.
- Reference-guided style analysis metadata for the supplied city illustration, layered landmark PSD, element catalogue, and animated diagram.
- Semantic Scene Planner for character explainers, architectural landmarks, infographic charts, product promos, corporate stories, and logo reveals.
- Persian/English text and voice planning.
- Automatic conversion from a creative brief into a v15-compatible autonomous AE manifest.
- Style presets and deterministic variation generation.
- Optional audio-sync marker architecture.
- Originality policy: reference style/structure guidance, not cloning branded templates or protected assets.

## End-to-end flow
Voice/Text → Creative Brief → Family + Style → Scene Plan → AE Manifest → Existing transactional runtime → Snapshot/Recovery/Exactly-once boundary → Render/Verify.
