# Foundation v27 — Advanced Original Character Generator

## Added
- Independent, original 2D character specification and generator.
- Deterministic operation keys for every generated character part.
- Character variants with style and hair variation.
- ExtendScript adapter that creates a fresh shape-based character composition in After Effects.
- No copying or extraction of external project character assets or rigs.
- Integration with v26 project intelligence and v25 action planning.

## Scope
v27 completes Phase 2 of the sequential roadmap: Advanced Original Character Generator. Advanced IK/FK rigging remains the next phase.
