# Foundation v26 workflow

1. Open the user-owned `.aep` in Adobe After Effects.
2. Run `foundation-v26/extendscript/project-inspector.jsx` through the authorized bridge.
3. Normalize the returned inspection report.
4. Analyze rig candidates and action compositions.
5. Build a semantic, original action library without copying third-party assets or rigs.
6. Plan one or more original characters and interactions.
7. Execute through the existing transactional, fenced, recoverable runtime.
8. Verify output and commit the job.
