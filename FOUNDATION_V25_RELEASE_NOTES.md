# AE BOSS OMEGA Foundation v25 — Autonomous Character & Motion Studio

## New capabilities
- Original generated 2D character runtime for After Effects.
- Natural-language and voice-to-character action planning.
- Action sequencing with deterministic operation keys for transactional/reconciled execution.
- Supported actions: idle, enter, walk, talk, point, wave, think, celebrate, present, exit.
- Rig schema and controller-keyframe reconciliation metadata.
- ExtendScript runtime that creates an original puppet from primitive layers and animates action controllers.
- Optional external-reference adapter for a user-installed `.aep`; it does not copy or embed third-party characters, rigs, expressions, or assets.

## Production boundary
The provided character toolkit is treated as an external user-owned reference/source project. v25 generates independent original puppet layers and action timelines; real mutation still requires a licensed After Effects host/bridge.
