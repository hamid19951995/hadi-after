# Foundation v11 Release Notes

Foundation v11 hardens the autonomous production runtime with:

- strict operation-id idempotency conflict detection;
- capability authorization before execution;
- asset-graph admission validation;
- explicit cancellation semantics;
- state-transition audit events;
- snapshot hash evidence and recovery coordination;
- safer terminal-state handling and status lookup.

The runtime still requires real After Effects host validation for production certification.
