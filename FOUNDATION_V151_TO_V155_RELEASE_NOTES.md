# AE BOSS OMEGA Foundation v151–v155

## v151 — Trace Normalization
Removes volatile fields and canonicalizes execution traces for deterministic comparison.

## v152 — Causal Consistency
Validates event dependencies and duplicate event identifiers.

## v153 — Evidence Quorum
Requires multiple independent valid sources to agree on one deterministic digest.

## v154 — Regression Budget
Adds explicit failure and P95 latency regression budgets.

## v155 — Unified Assurance Frontier
Combines deterministic trace stability, causal consistency, evidence quorum and regression budget. Local assurance remains distinct from live AE certification.
